# Security & responsible use

All six vulnerabilities in this repository were reported to the respective vendors and have
been patched. The proof-of-concept payloads here are **benign** (marker file + message box +
a video) and are provided as **C source only** — no compiled DLLs, no vendor installers, no
packaged extensions are included.

Use only on software you own, on an isolated virtual machine. Do not target others.
